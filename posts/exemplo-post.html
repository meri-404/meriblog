Como modelei o banco da minha biblioteca digital

22 de agosto de 2026 · projeto: Biblioteca Acadêmica Digital

Antes de escrever qualquer linha de Python, eu passei uma tarde inteira só desenhando tabelas no papel. Parecia contraintuitivo — eu queria programar, não desenhar retângulos — mas foi o que me poupou de refazer o banco inteiro três vezes depois.

O problema que eu queria resolver

Eu tinha dezenas de livros e artigos da faculdade espalhados entre anotações do Notion, PDFs soltos e uma planilha desatualizada. Queria um lugar único, com metadados consistentes, onde eu pudesse buscar por autor, assunto ou ano sem abrir sete arquivos diferentes.

Modelando as tabelas

Comecei identificando as entidades principais: livros, autores e emprestimos. Cada livro pode ter vários autores, e cada autor pode ter vários livros — uma relação muitos-para-muitos, resolvida com uma tabela associativa. 

CREATE TABLE livros (
    id INTEGER PRIMARY KEY,
    titulo TEXT NOT NULL,
    isbn TEXT UNIQUE,
    ano_publicacao INTEGER
);

CREATE TABLE autores (
    id INTEGER PRIMARY KEY,
    nome TEXT NOT NULL
);

CREATE TABLE livro_autor (
    livro_id INTEGER REFERENCES livros(id),
    autor_id INTEGER REFERENCES autores(id),
    PRIMARY KEY (livro_id, autor_id)
);
